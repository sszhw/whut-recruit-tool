# WHUT 校招信息采集与分析工具

面向**武汉理工大学校园招聘**（宣讲会 / 双选会 / 招聘信息）的本机小工具：把学校就业信息网的数据
抓下来，挑出值得去的场次和企业，并把网申要填的一大堆字段存成一份随时可复制、可导出成简历的档案。

- **数据只在你自己电脑上**，存 `data/` 目录，不上传任何服务器
- **一个命令启动**，之后全在浏览器里点，不用碰配置文件
- **AI 是可选的**：企业分析、投递推荐、简历识别要 Key；抓取、筛选、收藏、导出、简历档案全程离线可用

想改代码而不是用工具，请看 [docs/开发指南.md](docs/开发指南.md)（目录结构 / 数据口径 / 测试 / 技术栈）。

## 快速开始

### 1. 装依赖

需要 Python 3.10 及以上：

```bash
pip install -r requirements.txt
```

### 2. 启动

- Windows：双击项目根目录的 **`启动服务.bat`**（端口被占用时会提示，不会重复启动）
- 或者命令行：

```bash
python app/server.py --port 8765
```

然后浏览器打开 **http://127.0.0.1:8765**

> 启动脚本**不会自动打开浏览器**，起完手动访问上面的地址。

### 3.（可选）配 AI Key

顶栏齿轮 → **设置**，选提供商、填 Key、保存即可。也可以在项目根目录放一个 `config.json`：

```bash
cp config.example.json config.json      # Windows: copy config.example.json config.json
```

第一次打开会有三步上手向导（配 LLM → 抓数据 → 跑分析），走完自动消失。

## 怎么用

### 第一次：先把数据抓下来

顶栏 **数据维护** → 「按日期范围重新抓取」，选起止日期 → **开始抓取**。
抓取范围越大越慢，先抓一两个月就够用（宣讲会、双选会、招聘公告一次都抓）。

之后每天只要点顶栏 **更新数据**（增量）：只补新增，不重建文件，几秒钟。

跑任务的进度、日志、停止都在顶栏 **任务中心**，关掉页面也不会中断。

### 今日

首页直接回答三件事：今天新增了哪些招聘、近三天有哪些宣讲会、还有哪些待办。
数字卡片可以点，点了会跳到对应页面并自动带上筛选条件。

### 宣讲会

| 想做什么 | 怎么操作 |
|---|---|
| 找某家公司 / 某个城市 | 顶部搜索框（单位 / 地点 / 城市 / 公司地点） |
| 按条件收窄 | 「筛选」折叠：举办时间区间、公司地点（工作地）、宣讲会地点、线下 / 线上、只看收藏 |
| 看一周怎么排的 | 顶部切到 **周日历**，场次按开始时间摆到周一 ~ 周日 |
| 查撞车 | 有冲突时顶部会出现提醒条，点 **显示冲突** 才标红并列明细；**关闭冲突** 收回 |
| 收藏 | 行尾 ⭐；「批量 → 一键收藏全部」按当前筛选范围批量收藏 |
| 带走 | 「批量 → 导出收藏为 Excel / ICS」，ICS 可直接导进日历 App |

筛选条件在列表和周日历两个视图之间是共用的。

### 招聘信息

搜索标题 / 单位 / 正文，按发布日期或单位名排序，勾「只看今日新增」只看当天的增量。
感兴趣的加看板（我的 → 投递看板），也可以导出。

### 企业分析

顶栏 **数据维护** → 「企业 AI 分析」，填分析数量（0 = 全部）→ 开始分析。
结果会给每家企业判定性质（央企 / 国企 / 民企…）和工作地点，输出 CSV 与 Markdown 报告。

- 已分析的企业会缓存，重复运行自动跳过，可断点续跑
- 只想省 token：宣讲会工作地可以用 **离线** 口径（本地关键词 + 总部映射），免费
- 分析过了但改过提示词或公告变了：用「只算过期的」重分析，不重复烧 token

### 我的

四个子页，按使用顺序排：

1. **简历档案** —— 把网申要填的字段按模块存一份。可以上传 PDF / docx / 图片让 AI 识别，
   识别结果**逐项勾选后才写入**（AI 会编简历里没写的东西，别整盘接受）。
   填表时直接从这里复制。
2. **投递看板** —— 投了谁、什么状态、下一步做什么。
3. **求职偏好** —— 目标城市 / 岗位 / 薪资下限 / 企业性质 / 黑名单，存一次全局复用，
   推荐和筛选不用每次重填。
4. **投递推荐** —— 简历来源三选一：**直接读简历档案**（推荐页为空时会自动读一次，等于一键出结果）、
   上传文件、手动粘贴。三者都有时按「文件 > 档案 > 粘贴」取一份，当前用的是哪份写在按钮旁边。

### 顶栏其他

- **主题**：一键切「苹果 · 浅色」/「苹果 · 深色」，首次跟随系统偏好，之后记住选择
- **任务中心**：所有后台任务的进度、耗时、错误摘要、日志、停止

## 简历导出选哪一份

档案页底部有四个导出按钮，区别只在**给谁看**：

| 导出 | 给谁 | 说明 |
|---|---|---|
| **HR 版 .docx** | 真人 HR | A4 分区排版、右对齐时间、要点列表、右上角照片。高中经历和绩点排名不放 |
| **完整版 .docx** | 自己留档 / 需要全量字段的表单 | 与 HR 版**同款排版**，但把档案里全部模块字段一条不落写进去（家庭成员、学号、紧急联系人、证书编号都在） |
| **.md / .txt** | 校招系统的自动解析 | 一行一项、字段名用全角冒号、日期 `yyyy-MM-dd`，刻意不加任何排版 |

> 要「上传附件 → 自动解析填表」，用 **.md / .txt**。
> 两份 Word 都带表格和照片，喂给解析器会导致字段错位。

三份都包含档案里的**全部模块与字段**，不按字段名过滤。只有两类不进文档：
本地文件指针（`照片` 字段的值是个文件名）和带 ⚠️ / ⛔ / 见 § 的内部批注。

## AI 与 API Key

| provider | 接口 Base URL | 默认模型 | 用途 |
|----------|--------------|----------|------|
| `siliconflow` | https://api.siliconflow.cn/v1 | Qwen/Qwen2.5-72B-Instruct | 企业分析 / 流动分析(AI) / 投递推荐 / 简历识别 |
| `deepseek` | https://api.deepseek.com | deepseek-chat | 同上（OpenAI 兼容） |

- AI 调用失败（余额不足 / 网络错误）会自动降级为本地离线匹配，不会卡住流程
- Key 默认明文存在 `config.json`（已 gitignore）。想存进系统钥匙串：设环境变量 `WHUT_KEYRING=1`，
  没装 `keyring` 也不影响，自动退回原行为

## 数据放在哪

所有运行数据都在 **`data/`** 目录：抓取的原始文件、SQLite 主库、分析缓存与报告、
收藏、投递档案、个人照片、日志。文件命名与字段说明见 [docs/数据格式.md](docs/数据格式.md)。

- 换电脑：把 `data/` 整个拷过去即可
- 想重来：删掉 `data/` 后重新抓取（主库可由 `scripts/migrate_to_sqlite.py` 从原始 JSON 重建）
- 每日自动更新：把 `scripts/check_daily.bat` 挂到 Windows 计划任务（默认 09:00）

## 常见问题

**启动后页面打不开？**
先看命令行有没有报错。端口 8765 被别的程序占了就换一个：`python app/server.py --port 8766`。

**抓取很慢 / 没数据？**
抓取是按日期范围逐页拉的，范围拉太大自然慢；先试一个月。没数据先确认能正常访问学校就业信息网。

**企业分析跑不动？**
确认设置里填了 Key 且余额够。失败会自动降级离线，但离线口径只做关键词匹配，判定会粗一些。

**导出的 Word 在别人电脑上字体不对？**
文档里中文字体已按 Word/WPS 的规范写入，若仍异常，通常是对方缺这款字体，换个常见字体即可。

**页面改了没生效？**
`ui.html` 每次请求现读，刷新即可。改的是 `.py` 就要**重启服务**。

## 隐私与脱敏

这是一个**本机单机**工具。仓库里不含任何个人数据 —— 下表内容全部由 `.gitignore` 排除，
不会被 `git add -A` 带上：

| 文件 / 目录 | 内容 | 风险 |
|---|---|---|
| `config.json` | LLM API Key | 密钥泄露 |
| `data/投递档案.json`、`投递档案.json.bak-*` | 姓名 / 证件号码 / 手机号 / 家庭成员 | 真实身份信息 |
| `data/简历照片.*` | 个人照片 | 人脸 + 姓名 |
| `app/_upload_tmp_*` | 简历识别的上传临时件（PDF / docx / 图片） | 整份简历 |
| `data/求职偏好.json` | 目标城市 / 岗位 / 薪资下限 / 黑名单 | 求职倾向 |
| `data/*.db`、`*_原始数据.json`、`*_缓存.json` | 抓取与分析产物 | 体积大、含抓取时段 |
| `data/服务日志.jsonl`、`任务历史.json`、`任务日志/` | 运行日志 | 可能含本机路径 |
| `outputs/` | 导出的简历 Word、界面走查截图 | 真实简历全文 |

**推送公开仓库前的自检**：

```bash
git status --porcelain                        # 确认暂存区里没有上表任何一项
git grep -nI -E 'sk-[A-Za-z0-9]{8,}'          # API Key
git grep -nI -E '[0-9]{17}[0-9Xx]'            # 身份证号
git grep -nI -E '1[3-9][0-9]{9}'              # 手机号
```

测试夹具同样不许出现真实个人信息：证件号码用示例值 `110101200001011234`，
简历示例用「张三 / 李四」这类占位姓名。
