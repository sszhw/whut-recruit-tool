# 数据文件说明

本项目在 **`data/` 子目录**读写运行数据（各脚本 `DATA = ROOT / "data"`，`config.json` 仍在项目根）。
上传 GitHub 时，真实数据与产物均由 `.gitignore` 排除；如需示例，请放入 `samples/`（勿提交真实数据）。

## 原始数据

| 文件模式 | 内容 |
|----------|------|
| `宣讲会_<年>_原始数据.json` | 宣讲会列表（含 `宣讲会` 键，字段见下） |
| `武汉理工大学招聘信息_<起>_至_<止>_原始数据.json` | 招聘信息 + 双选会（含 `招聘信息`、`双选会` 键） |

宣讲会条目常用字段：
`id`、`com_id_name`(单位)、`title`(标题)、`hold_date` / `hold_starttime` / `hold_endtime`(时间)、
`address` + `city_id_name`(地点)、`air_type`(0=线下)、`addtime`(秒级时间戳)、`httpurl`(原网页)、
`remarks` / `purpose`(正文)、`JobList`(岗位，含 `city_id_name`)。

## 分析 / 导出产物

| 文件 | 内容 |
|------|------|
| `企业分析_国企与工作地点.csv`、`企业分析报告.md` | 企业性质 + 工作地点分析结果 |
| `企业分析_缓存.json` | 企业分析缓存（重复运行自动跳过已分析企业） |
| `宣讲会_工作地流动.csv`、`宣讲会_工作地流动报告.md` | 宣讲会企业工作地流动分析 |
| `武汉理工大学招聘信息_*_{招聘信息,双选会,宣讲会_2026年}.csv` | 每日导出快照 |

## 配置

| 文件 | 说明 |
|------|------|
| `config.json` | 运行配置（LLM 提供商 + API Key + 模型）。含敏感信息，不入库 |
| `config.example.json` | 配置模板（无 Key），可复制为 config.json 后填写 |
