# 界面分级设计方案

**对象**：`app/ui.html`（2796 行单文件）+ `app/api/*.py` 14 个蓝图
**目标**：解决"导航平铺 8 项、同类功能散落、日志框重复"导致的认知负担
**性质**：规划文档，尚未改动任何代码
**证据来源**：`ui.html` 结构读取、`api/*.py` 路由盘点、`services/status.py` 阅读
**关键假设**：使用者是求职者本人（单人本地工具），每天打开 1~3 次，桌面为主、手机为辅

---

## 1. 视觉主题

### 现状判断

现有令牌系统质量不错，已经具备 `--sp-1..6` 间距刻度、`--fs-xs..2xl` 字号刻度、`--tap:44px`、
语义文字色（`--accent-text` / `--ok-text` / `--danger-text`）与三套主题。**不重建设计系统**，
只补"层级表达规则"。

### 真正的冗余来自结构，不是配色

| 症状 | 具体证据 | 性质 |
|---|---|---|
| 导航 8 项平级 | `nav` 内 8 个 `role="tab"`，顺序既非频率序也非工作流序 | 结构 |
| 后台作业与日常浏览同级 | 「抓取数据」(跑一次) 与「宣讲会」(每天看) 占同样权重 | 结构 |
| 日志框 ×4 | `crawlLog` / `analyzeLog` / `checkPreachLog` / `flowLog`，且已有任务中心抽屉 | 重复 |
| 模型下拉 ×4 | `#modelSel` `#resumeModel` `#visionModel` `#llmModelInput` | 重复 |
| 偏好输入 ×2 且冲突 | 推荐页 `workPlace`/`companyType`（临时） vs `/api/prefs`（持久，无 UI） | 重复 + 缺失 |
| 导出 ×5 分散 3 页 | 总览 3 个 + 宣讲会 2 个 | 分散 |
| 卡片内功能区过多 | 宣讲会卡内 7 个功能区（视图切换/冲突条/8 筛选/4 批量/表格/分页/2 段 hint） | 密度 |
| 一级导航图标不齐 | 8 项中 7 项带 emoji，「投递看板」没有 | 一致性 |

### 视觉主线

**中性结构 + 单一强调色**，operational / 扫读型密度。
层级一律用**留白 + 标题字号 + 一条分隔线**表达，**不再靠多套一层卡片边框**。

**禁止**：card 套 card；同一屏出现两个以上主色按钮；用新增色相表达新功能。

## 2. 配色

沿用现有令牌，不新增色相。仅补两个容器角色：

| 角色 | 变量 | 浅色值 | 用途 |
|---|---|---|---|
| 页面底 | `--bg` | `#f8fafc` | 画布 |
| 卡片面 | `--card-bg` | `#ffffff` | 一级内容容器 |
| 次级面（新增） | `--surface-sunken` | `#f1f5f9` | 表格表头、折叠区底、只读块 |
| 浮层面（新增） | `--surface-raised` | `#ffffff` + `--shadow` | 抽屉、下拉、toast |
| 主行动 | `--accent` | `#6366f1` | 每屏最多 1 个实心主按钮 |
| 强调文字 | `--accent-text` | `#4f46e5` | 可点文字、链接（白底 6.29:1） |
| 警告 | `--warn-text` | `#b45309` | 冲突提醒、数据过期（白底 5.02:1） |
| 危险 | `--danger-text` | `#b91c1c` | 停止、删除（白底 6.47:1） |

```css
:root {
  --surface-sunken: var(--panel2);
  --surface-raised: var(--panel);
}
```

**对比度说明**：上表浅色值沿用项目 `[data-theme="light"]` 中已有且已注释对比度的令牌，
未重新计算。三套主题切换后需各自复测，见第 8 节"待执行检查"。

## 3. 字体

沿用现有刻度，字距恒为 `0`（项目已满足）。

| 角色 | 变量 | 用途 |
|---|---|---|
| 页面标题 | `--fs-xl` 17px / 500 | 顶栏产品名 |
| 卡片标题 | `--fs-lg` 15px / 500 | 每张卡唯一 `h2` |
| 小节标题 | `--fs-md` 14px / 500 | 卡内 `h3`、分组名 |
| 正文 / 表格 | `--fs-md` 14px / 400 | 表格单元格、列表 |
| 辅助 | `--fs-sm` 13px / 400 | hint、表头、分页 |
| 指标数字 | `--fs-2xl` 28px / 500 | 关键指标数值 |

**规则**

- 每张卡**只有一个 `h2`**，卡内分组用 `h3`，不出现第四级。
- 长标题（企业名、公告标题）单行截断 + `title` 属性，不换行撑高行。
- 表格数字列右对齐且等宽（`font-variant-numeric: tabular-nums`），避免分页时列宽跳动。

## 4. 组件样式

### 4.1 一级导航（8 → 4）

```html
<nav role="tablist" aria-label="主功能导航">
  <button role="tab" data-tab="today">今日</button>
  <button role="tab" data-tab="preachs">宣讲会</button>
  <button role="tab" data-tab="recruits">招聘</button>
  <button role="tab" data-tab="mine">我的</button>
</nav>
```

- **去掉全部 emoji**。理由：8 项中 7 项有图标 1 项没有，视觉权重已经不齐；
  emoji 跨平台字形不一致，且与中文基线不对齐。纯文字 4 项在 375px 下也不折行。
- 「设置」降为顶栏右侧齿轮图标按钮（44×44，带 `aria-label`）。
- 「更新数据」为顶栏**唯一实心主按钮**。

### 4.2 筛选收纳器（新增，两个列表页共用）

现状：宣讲会 8 个筛选控件 + 1 行 checkbox + 4 个批量按钮常驻可见。

```
[ 搜索框（常驻） ]  [ 筛选 (3) ▾ ]  [ 批量 ▾ ]        ← 单行工具条
```

- 默认常驻：搜索框 + 「仅今天及以后」（宣讲会）/「只看今日新增」（招聘）。
- 其余筛选项进「筛选」下拉面板，`aria-expanded` 控制，选中项数显示在按钮上。
- 展开状态按页面记入 `localStorage`，不每次重填。
- 批量操作（收藏全部 / 取消收藏 / 导出 Excel / 导出 ICS）进「批量」菜单。

### 4.3 任务启动器（替换 4 处日志框）

- 页面内不再出现 `<pre class="log">`；进度与日志一律走任务中心抽屉。
- 任务卡片统一三态：`idle`（说明 + 主按钮）/ `running`（进度条 + 停止）/ `done`（上次结果 + 再跑一次）。
- 长任务启动后，**顶栏任务中心徽标数字 +1 并出现呼吸点**，页面内按钮同步转 running。

### 4.4 卡片语法（统一）

```
┌ 卡片 ────────────────────────────┐
│ h2 标题                 [次要操作] │   ← 头部，右侧最多 1 个次要操作
│ ─────────────────────────────── │   ← 1px 分隔线（仅当下方是数据区）
│ 内容 / 表格                       │
│ （最多 1 行 hint）                │
└──────────────────────────────────┘
```

现状宣讲会卡违反此语法（7 个功能区），需拆为：
卡片头（标题 + 视图切换）→ 工具条 → 冲突条 → 表格 → 分页。

## 5. 布局

### 5.1 各层内容契约

**L0 常驻壳层**
- 顶栏单行：产品名 · 数据新鲜度徽章 · [更新数据] · 任务中心 · 齿轮 · 主题
- 任务中心抽屉（保留现实现）：全部任务的进度 / 日志 / 停止
- 企业详情抽屉（保留现实现）
- 高度固定，不随内容滚动

**L1 今日**（打开即到达）
1. 状态条：数据更新到何时 + 待办数 + 「更新数据」
2. 今日行动卡：可点卡片，跳转自带筛选
3. 关键指标：一行 4~5 个数值
4. 折叠：数据健康 / 分布统计 / 导入导出（**保留现有 `<details>` 做法，这是项目里已经做对的部分**）

**L1 宣讲会**
- 卡头 + 视图切换（列表 / 周日历）
- 单行工具条（搜索 + 筛选 + 批量）
- 冲突提醒条（无冲突不渲染）
- 表格 / 周日历网格
- **移出**：「检查宣讲会更新」卡、「工作地流动分析」卡 → L3 数据维护

**L1 招聘**
- 单行工具条（搜索 + 只看今日新增 + 排序）
- 表格 + 分页

**L2 我的**（卡内分段控件四选一，顺序 = 使用顺序：简历档案 → 投递看板 → 求职偏好 → 投递推荐；
默认落在第一项「简历档案」——推荐是档案的下游消费者，所以排最后）
- 投递推荐：主路径 =「来源三选一（**简历档案** / 上传文件 / 粘贴）+ 生成推荐」。
  档案可以直接读（`/api/profile/render?format=md`），不必把档案里的东西重抄一遍；
  三者都有时按「文件 > 档案 > 粘贴」取一份，按钮旁如实说明本次用哪份；
  `workPlace`/`companyType` 默认读求职偏好；`visionModel`/`resumeModel`
  收进「高级选项」折叠
- 投递看板：阶段统计 + 列表；**删除手工新增表单**（保留列表与抽屉的内联入口）
- 求职偏好（新增，接 `/api/prefs`）：目标城市 / 目标岗位 / 薪资下限 / 企业性质 / 黑名单

**L3 数据维护**（顶栏「更新数据」旁的 `⋯` 菜单唤起，非导航项）
- 更新数据（增量，主）
- 按日期范围全量抓取
- 企业 AI 分析
- 宣讲会工作地流动分析

**L4 设置**（顶栏齿轮）
- LLM 配置（保留）
- 当前模型（唯一模型决策点）
- 导出 / 导入（从总览折叠区移入）
- 主题

### 5.2 栅格与间距

- 内容区最大宽 `1200px`，居中，左右 `gutter 24px`（移动端 `16px`）。
- 卡片间距 `--sp-5` 22px；卡内元素间距 `--sp-3` 12px；卡内 padding `--sp-4` 16px。
- 分组间距 > 相关项间距 > 元素内间距，这条关系优先于具体数值。
- 表格行高恒定 `44px`，状态切换不改变行高。

## 6. 深度与层级

| 层 | 元素 | 边界表达 |
|---|---|---|
| 0 | 页面底 `--bg` | 无边框无阴影 |
| 1 | 卡片 | 1px `--border` + `--radius` |
| 2 | 表头 / 折叠区底 / 只读块 | 仅底色 `--surface-sunken`，**不加边框** |
| 3 | 抽屉 / 下拉 / toast | `--shadow` + `--surface-raised` + 遮罩 |

规则：**一个边界只用一个线索**。已经是底色的块不再加边框；已经是卡片的块不再加阴影。
禁止 card 内再套 card。

## 7. 注意事项

1. **不要删除后端接口**。本方案只改 `ui.html` 的组织方式，`app/api/**` 全部保留；
   `/api/prefs` 反而是从"有后端无界面"变成"有界面"。
2. **「更新数据」与「全量抓取」必须视觉区分**。前者幂等、安全、可每天点；
   后者会新建数据文件。按钮样式与文案都要区分，且后者需要二次确认。
3. **任务中心是唯一日志出口**。删除页面内 `<pre>` 后，必须保证任务中心能查历史日志
   （现已有 `data/任务日志/<task_id>.log` 与「查看日志」，能力具备）。
4. **周日历视图沿用列表筛选**。现状已如此，重构时不要破坏这个隐式契约。
5. **emoji 去留需你确认**。一级导航去掉 emoji 是本次建议，若你偏好保留图标，
   则应改为统一 SVG 图标集（8 项补齐，不能只有 7 项有）。
6. **未验证项**：三套主题（`apple` / `light` / `dark`）切换后的对比度未实测；
   375 / 768 / 1024 / 1440 四个宽度未渲染验证；本轮为规划，未做浏览器检查。

## 8. 响应式行为

| 断点 | 变化 |
|---|---|
| ≥1024px | 4 项导航横排 + 顶栏完整；卡片双栏栅格 |
| 768–1023px | 导航横排但收紧 padding；指标卡 2×2 |
| <768px | 导航横向滚动吸顶；工具条换行；筛选面板改底部抽屉 |
| <375px | 表格关键列保留（时间/单位/地点），次要列进详情抽屉 |

- 触摸目标 ≥ `--tap` 44px（项目已定义，需覆盖到筛选面板与批量菜单项）。
- 焦点环用 `--focus-bg`，键盘 Tab 顺序 = 视觉阅读顺序（工具条 → 内容 → 分页）。
- `prefers-reduced-motion` 已支持（数字滚动已判断），新增的呼吸点同样需遵守。
- 加载态用表格骨架行，高度与真实行一致，避免内容到位时的跳动。

任务 running 状态下切换页面的状态同步。以上均未执行。
