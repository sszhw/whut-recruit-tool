## 统一数据口径

原始数据散落在多个 `*_原始数据.json`（按抓取日期命名）中。历史上页面展示会跨文件合并去重，
而企业分析 / 投递推荐只读「最新修改的那个文件」——一旦最新文件只是一次当日小快照，
分析样本就会远小于页面展示范围。

现在统一由 `app/repository.py` 提供唯一入口：

| 能力 | 说明 |
|------|------|
| `raw_items(kind)` | 跨**全部**原始文件合并、按学校网站 ID 去重（新文件优先），`kind ∈ recruit / fair / preach` |
| 缓存 | 按「文件列表 + mtime + 大小」签名缓存，数据变化自动失效；避免每次请求重复解析几十 MB JSON |
| `master_summary()` | 招聘 / 双选会 / 宣讲会的记录数、覆盖日期、最近更新时间、详情缺失 |
| `companies()` | 企业清单（企业分析与投递推荐共用），含公告数与最长正文 |

接入点：`/api/status`、`/api/health`、`/api/actions`、招聘 / 双选会 / 宣讲会列表、`analyze.py --merge`、
`resume.build_companies()`。**新增读取数据的代码请一律走 repository，不要再自己 glob「最新文件」。**

## 测试

```bash
pip install pytest            # 或 pip install -e ".[dev]"（含 ruff）
python -m pytest              # 332 项
python -m ruff check app tests
```

测试使用临时目录（`tests/conftest.py` 会把数据目录指向 `tmp_path`），
**不会读写项目真实数据**；任务管理器用例会启动真实子进程并断言日志/进度/持久化。

### 端到端冒烟（需要真实 API Key）

```bash
python scripts/e2e_smoke.py   # 11 组检查：状态 / LLM 连通 / 企业 / 宣讲会 / 偏好 / 真实分析 / 看板 / 推荐 / 导出
```

单测再全也测不到「接口接线」类 bug——每层单测都把自己那一层的入参打桩了。
这个脚本用**真实 Key + 真实数据**把主链路跑一遍（会真的烧一点 token：分析 2 家企业 + 一次简历推荐），
专治「只在 web 路径的参数组合下才暴露」的问题（历史上 `--source` 默认值写错、页面
「AI 分析企业」100% 必挂就是这么抓出来的）。

### 前端改动怎么验

前端是单文件 `app/ui.html`，没有构建、没有编译器兜底。改完至少过一遍：

1. `pytest tests/test_ui_contract.py tests/test_ui_resume_source.py tests/test_ui_preach_conflict.py tests/test_ui_mobile_header.py`；
2. 栈式标签配对 + CSS 花括号计数平衡；
3. 全文件 `id` 唯一（`$('x')` 只返回第一个，重名会让后半个功能静默失效）；
4. `node --check` 跑一遍 `<script>`；`onclick` 里引用的函数是否都有定义。

## 移动端尺寸基线

窄屏规则分散在三处，各写在各自主管的区域里（不要合并成一段）：

| 位置 | 管什么 |
|---|---|
| 基础 `<style>` 的 `@media (max-width: 640px)` | 表单控件尺寸、输入字号、页面边距、`.chip` 等触摸目标 |
| `#apple-theme` 的 `@media (max-width: 640px)` | 卡片间距、圆角、`.card` 内边距（会覆盖上一段） |
| 文末的 `@media (max-width: 640px)` | 顶栏两行网格、「⋯」浮层与遮罩 |

当前对齐的规范值（来源：iOS HIG 44pt / Material 48dp / 正文 16–17sp）：

| 项 | 取值 | 说明 |
|---|---|---|
| 最小触摸目标 | 44px（`--tap`） | 取 iOS 44pt 与 Android 48dp 的下限；顶栏按钮、`.chip`、`.pfilter-check`、`.favbtn`、纯图标「⋯」都走这个 |
| 输入控件字号 | ≥16px | 低于 16px 时 iOS/Chrome 会「聚焦自动放大」。改这条要连 `.prof-kv textarea`（有 `font: inherit`）一起改 |
| 页面左右边距 | 16px | `header` / `nav` / `main` 三级同宽，规范区间 16–20 |
| 卡片内边距 | 13–16px | 规范区间 12–16 |
| 安全区 | `env(safe-area-inset-*)` | 与 `viewport-fit=cover` **必须成对**：`body` 管左右、`main`/`.tasklist` 管下、`.toast` 管上、`.taskpanel`/`.cpdrawer` 管右（`fixed` 元素不吃 `body` 的内边距） |
| 间距刻度 | 8 的倍数 | 令牌 `--sp-2/4/6` = 8/16/30；历史遗留的 13px 一类数值未统一，改动时不要顺手替换 |

窄屏排布优先用**写死的 `grid-template-areas`**，不要用 flex 自动换行：换行的规则是
「这一行放不下就另起一行」，在 320px 上会把元素甩到意料之外的行。顶栏就是踩过这个坑后改的网格。

浏览器验证时注意：`bsk emulate` 与桌面浏览器里 `env(safe-area-inset-*)` 一律解析为 0，
所以「量出来没变化」只能证明**非刘海环境没被改坏**，不能证明刘海屏上是对的。
真实设备（尤其横屏）需要人工过一眼。

## 技术栈

- 后端：Python + Flask（`app/server.py` 只做装配，路由按域拆成 `app/api/` 下的蓝图），
  业务规则在 `app/services/`（不 import flask），后台任务以子进程 + 日志轮询实现
- 前端：原生 HTML/CSS/JS（`ui.html`），苹果风浅 / 深两套主题
- LLM：OpenAI 兼容接口（硅基流动 / DeepSeek），结构化 JSON 输出 + 失败降级
- 导出：CSV（UTF-8 BOM）与 Excel（openpyxl）；简历用 python-docx
- 采集：`requests` + `mobile.php` JSON 接口，按 `id` 增量去重

## 界面分级

一级导航只有四项，按「多久用一次」分层，后台作业与配置不占导航位：

| 层 | 位置 | 内容 |
|---|---|---|
| L0 | 顶栏常驻 | 数据新鲜度 · 更新数据 · 任务中心 · 设置 · 主题 |
| L1 | 一级导航 | 今日 / 宣讲会 / 招聘 / 我的 |
| L2 | 一级导航「我的」 | 简历档案 · 投递看板 · 求职偏好 · 投递推荐 |
