# 开发日志

## 2026-09-09 · 数据文件归档到 `data/` + 数据路径重构

### 背景
项目根目录长期散落大量抓取 / 分析产物（原始数据 JSON、CSV、Markdown 报告、分析缓存、宣讲会收藏），
不便管理。本次把「运行数据产物」统一收敛到根目录下的 `data/` 子文件夹，并同步重构各脚本的数据读写路径。

### 具体改动

**1) 新建 `data/` 目录并归档数据产物**
- 移入 12 个文件：各类型 `*_原始数据.json`、`*_工作地流动.csv`、`*_招聘信息.csv`、`*_双选会.csv`、
  `*_宣讲会_*.csv`、`*报告.md`、`企业分析_缓存.json`、`收藏_宣讲会.json`。
- `config.json` / `config.example.json` 作为**配置**保留在项目根，不随数据搬走。

**2) 数据路径重构（涉及 9 个脚本）**
- 引入统一约定 `DATA = ROOT / "data"`，把脚本对数据文件的读写从根目录改到 `data/`：
  - `server.py`：新增 `DATA` 常量；`CACHE_PATH` / `FAV_PATH` / `_newest_glob` / `_company_work_map` /
    `_iter_recruit_files` / `_count_ids` / 工作地流动读写 / 分析产物导出 / 招聘 CSV 导出 / 传给 crawler 的
    `--output` / 传给 `resume.build_companies` 的数据目录，全部改用 `DATA`。
  - `crawler.py`：`--output` 默认值改为 `…/data`。
  - `analyze.py` / `resume.py`：数据目录由 `workdir = …/data` 表示（等效）。
  - `analyze_preach.py` / `check_recruit_update.py` / `check_preach_update.py` / `run_daily.py` /
    `_run_preach.py`：新增 `DATA` 常量并替换数据文件路径；写入类脚本额外 `DATA.mkdir(...)` 确保目录存在。
- `.gitignore` 本身已用无前导斜杠的 pattern 排除这些数据文件，故移入 `data/` 后仍不会入库。

### 验证

  `/api/preachs`、`/api/preach/favs`、`/api/crawl/dates` 均正常从 `data/` 读到数据。

  （更新为 629 场 + CSV 629 条 + 工作地映射新增 1 家），读与写链路均正常。
- 针对「数据路径重构」的 ad-hoc 验证脚本共 24 项检查全部通过（路径常量解析、数据引用不再经 `ROOT` 拼接、
  新增路径 `glob` 实读命中、关键文件在位、`config.json` 保留根目录）。
