# data/ —— 运行数据目录

本目录放**运行期数据**（抓取产物、分析缓存、收藏、日志、投递档案、个人照片），
全部由根目录的 `.gitignore` 排除，**不会进版本库**。仓库里只保留这一个说明文件，
好让克隆下来的项目目录结构完整。

## 目录里会有什么

| 文件 | 来源 | 说明 |
|---|---|---|
| `*_原始数据.json` / `*.db` | 页面「抓取 / 更新数据」 | 原始抓取结果；`*.db` 由 `scripts/migrate_to_sqlite.py` 从 JSON 导入，可随时重建 |
| `宣讲会_*.csv`、`宣讲会_工作地流动.*` | 宣讲会页面 / 流动分析 | 场馆、工作地映射 |
| `企业分析_*` | 企业分析 | 企业性质 + 工作地点判定结果与报告 |
| `投递档案.json` | 「我的 → 简历档案」 | **含真实个人信息**，已 gitignore |
| `简历照片.*` | 简历档案的照片导入 | **人脸 + 姓名**，已 gitignore |
| `求职偏好.json` | 「我的 → 求职偏好」 | 目标城市 / 岗位 / 薪资下限 / 黑名单，已 gitignore |
| `服务日志.jsonl`、`任务历史.json`、`任务日志/` | 服务与后台任务 | 运行日志，已 gitignore |

## 脱敏提醒

- 需要示例数据放进仓库时，**先脱敏再放入 `samples/`**，不要把真实数据改名后提交。
- 公开仓库前跑一遍 README「隐私与脱敏」里的四条 `git grep` 自检。
